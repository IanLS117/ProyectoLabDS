# SIGETI · PBI-TIC-US-02: Mis tickets

Permite que cada usuario consulte los tickets que ha registrado y conozca su estado actual.

El listado muestra el folio, equipo, problema, fecha y estado. Incluye un botón para actualizar la información y un aviso cuando la cuenta no tiene tickets.

Se comprobó que cada cuenta vea únicamente sus tickets y que la sección esté protegida para los demás roles y para quien no ha iniciado sesión.

Esta rama parte de la base compartida del Sprint 2. La rama **PBI-TIC-US-03** incluye este avance y agrega la atención y el cierre con solución; puedes usarla para probar todo junto.
